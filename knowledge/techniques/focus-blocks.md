# Work in focus blocks

Tags: focus, pomodoro, deep work, concentration, task switching, distracted while working

## When it helps
You start working and drift to a feed within minutes. Attention is easier to hold for a short, defined stretch than for an open-ended afternoon.

## How to do it
Choose one task, work on only that for 25 minutes, then take a 5-minute break away from screens. After three or four blocks, take a longer break. If a distracting thought comes up during a block, write it down and return to the task.
